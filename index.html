Sobre

Trabalho com backend desde 2018, passando por PHP, Laravel e Symfony até chegar em Node.js com NestJS. Hoje lidero o time de backend do Grupo Imagetech, onde divido o dia entre arquitetura, revisão de código e as entregas que precisam sair com qualidade.

Gosto de saber o caminho inteiro de uma requisição: do banco, passando pela fila e pelo proxy, até o servidor. Por isso mantenho minha própria infraestrutura, com Docker e um proxy reverso, onde rodam os projetos pessoais desta página.

Também dou aula de segurança cibernética em curso técnico. Ensinar me obriga a explicar o que eu acho que já sei, e quase sempre aprendo alguma coisa no caminho.

Projetos

  • ByteValor

    Portal de notícias com mais de 60 mil matérias publicadas. Cada artigo ganha versão em áudio, narrada por um serviço de voz sintética que roda no próprio servidor, sem API paga.

    Next.js, NestJS, PostgreSQL, Redis, Piper TTS

  • BP Tracker

    Acompanhamento de saúde: pressão arterial, glicemia e peso, com exames laboratoriais anexados. A IA gera análises a partir dos exames novos, e o histórico pode ser compartilhado com o médico.

    NestJS, React, PostgreSQL, MinIO

  • Brag Doc

    Registro de conquistas profissionais que importa tickets do Jira e histórico do Git. Com IA, transforma o registro em relatório para avaliação de desempenho, argumento de promoção e currículo sob medida para uma vaga.

    NestJS, MongoDB, Gemini

  • consulta-cnpj-ws

    Pacote npm para consultar dados de empresa pelo CNPJ com uma chamada, usando a base aberta do OpenCNPJ.

    Node.js, npm

  • node-cep-correios

    Pacote npm para buscar endereço pelo CEP, feito para consultas em massa sem bloqueio. Sem dependências, usa o fetch nativo do Node 20.

    Node.js, npm
